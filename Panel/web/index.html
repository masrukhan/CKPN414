                  Metode PD & LGD (Master!D17)— di sheet Master

                  Metode konsolidasi dan Top-N terkunci setelah ada periode Final di tahun ini.

                  Susunan grup

                  Beri nama grup untuk setiap kode segmen. Kode dengan nama grup yang sama dihitung bersama (PD & LGD gabungan). Berlaku untuk seluruh periode di tahun ini.

                  Metode konsolidasi tahun ini (satu untuk semua grup)

                  Tidak dapat diganti setelah ada periode tahun ini yang dikunci (Final), kecuali kunci periode tersebut dibuka.

                  Top-N debitur CKPN Individu per grup (sesuai SOP)

                  Daftar grup mengikuti nama grup di atas. Hitung grup dari panel menulis Top-N grup tersebut ke Master!C10, dan Simpan grup ditolak bila Top-N di Master berbeda. Tidak dapat diganti setelah ada periode Final di tahun ini.

                  PD & LGD ABA

                  Nilai ini menimpa Summary C21:C23 (PD industri, LGD porsi dijamin LPS, LGD porsi di atas plafon) untuk semua periode di tahun ini. Diterapkan otomatis di awal setiap perhitungan panel, sesudah Refresh Summary, dan sebelum Simpan grup. Isi sesuai kebijakan / addendum ABA yang berlaku.

                  Referensi KC hapus buku (KC2900)

                  LGD ER memecah rekening hapus buku KC2900 per segmen (KC0600–KC1100). Kode KC dicari otomatis dari file tahunan Master!D60:D65: rekening yang sama di sheet KC0600–KC1100, lalu KC mayoritas kode produk (digit awal nomor rekening). Rekening yang tetap tanpa Kode KC tidak masuk LGD ER grup mana pun — lengkapi di bawah, lalu hitung ulang grup. File sumber tidak lagi ditulis (kolom M).

                  Perlu dilengkapi
                  Kode produk

                  Digit awal nomor rekening tanpa nol di depan. Baris kuning = kode produk tersebar ke beberapa KC; pertimbangkan menambah panjang kode atau mengisi KC manual.

                  Isian manual
                  Berbeda dengan kolom M
                  Dikecualikan
                  Data & sistem

                  User yang boleh menyimpan, mengoreksi, dan menetapkan periode tercantum di config\pengirim.txt dalam folder library: satu nama user Windows per baris, tanpa nama PC. Bila file kosong atau tidak ada, semua user boleh menyimpan. User lain hanya bisa melihat.

                  Kelola database

                  Hapus data periode atau kosongkan database, misalnya setelah simulasi untuk memilih metode. Setiap penghapusan didahului salinan arsip di library\backup.
